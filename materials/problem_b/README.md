## 前两问的数据与条件

题目第1页给出问题1、2。附件没有前两问的测量表；`problem1/examples/`、`problem2/examples/` 均为自建验证输入。

| 条件 | 数值或含义 | 题面位置 |
| --- | --- | --- |
| 源所在区域 | 原点为圆心，半径1800米 | 第1页 |
| 坐标和角度 | +x向东，+y向北，角度由+x轴逆时针，单位度 | 第1页、附录2(1) |
| 示向误差 | ±1°，同一点重复测量不能消除固定误差 | 附录2(1) |
| 有效接收半径 | 每个源固定但未知，在1000至1500米之间 | 附录2(2) |
| 正常示向读数 | 在覆盖范围内且距源大于5米 | 附录2(9) |
| 移动与检测时间 | 5米/秒、检测5秒 | 附录2(5)(6) |
| 光学精确定位与清除 | 距源不超过20米；定位3秒，清除2秒 | 附录2(8) |

第二点允许离开目标圆域：附件1第2.2节明确“可以超出目标区域”。1800米圆域约束的是干扰源位置。

## 重新提取

在仓库根运行 `python scripts/prepare_materials.py`，需要 `pypdf`。脚本从自身位置确定仓库路径，也支持从其他工作目录用绝对路径调用。若发现工作副本被改动，将停止并报错，不覆盖改动。

本次只处理前两问的本地建模和验证；模拟器正式测试、账号及加密日志属于问题3、4。
