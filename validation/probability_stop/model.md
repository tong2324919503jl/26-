# 概率提前停止的含义与边界

此功能是承担漏清风险的实验，安全 v4 仍是默认。分数表示额外假设下的全清概率，不能称为平台成功率。

设已发现且成功清除 k 个不同频道，N 的先验为 π_n，范围为 10 至 16；频道等概率不放回分配，各源配置独立同分布。q 表示一个固定源躲过全部实际完整扫描的概率。则

\[
P(全清\mid H)=\left[\sum_{n=k}^{16}\frac{\pi_n}{\pi_k}{n\choose k}q^{n-k}\right]^{-1}.
\]

均匀 N 先验对应 nominal；robust 取五种位置、半径和朝向模型中的最大 q，并改用 π_n∝2^n。组合因子来自对未知频道子集求和。k<10 或仍有阳性未清源时禁止早停；清除16源则已有确定性证明。未知频道扫描史不同，应使用各自 q 的对称多项式；目前只取所有未知频道均已执行的完整扫描点。

严格的后验公式还要求公开历史在该先验下有正似然。例如“所有源均在边界”的压力模型可能与已经清除的内圈源矛盾，本实验仍保留它来考察未知源最难发现的情况。因此 robust/guarded 是先验敏感性分数，不能称为对完整观测历史的严格贝叶斯后验下界；数值上界只针对各自声明的源配置分布。

同一源在多点是否收信相互关联，特别是定向源背面始终可能无信号。模型让同一个位置、半径、朝向粒子经历全部扫描，不能相乘单点漏检率。自适应路径可条件于公开历史处理，但不能把计划点当已扫描点。已知源的观测似然在独立模型内抵消；簇团、共同朝向等依赖会破坏 q 的幂次公式。P4 nominal 的独立半数类型还放宽了“至少一个全向和一个定向”的条件，因此不是严格题面后验。

guarded 另控制积分误差。解

\[
M\,\mathrm{KL}(\hat q\|u)=\log(F/0.001)
\]

得到单侧 q 上界，再代入保守后验。F 含五先验及每种布局的全部扫描子集：P3 为5(24·2⁷+16·2¹⁰)，P4为5·2²²。仅支持属于同一合法布局的点集；其他点禁用 guarded。1e−6米匹配容差由0.001米检测内缩保护。有限集合同时界允许据粒子选择路径和停点；α=0.001控制**每问固定先验积分的数值误差**，不控制模型错设或平台漏清率。`+1/M`本身只是防零保护。

当前131072粒子反例来自公开开发例P4 index14：原10源清除后，nominal=0.990557仍提前退出。追加一个合法定向源、保持同一seed，两次运行的310个动作和公开响应完全相同，实际却只清10/11。安全v4继续可清11/11；robust=0.295704、guarded=0.265772均挡住此例。完整案例在[反例文件](../../problem4/examples/probability_stop_counterexample.json)，证据在[independent_audit.json](independent_audit.json)。

旧32k实验另保留：同一旧停点换三个积分seed得0.986896—0.990883，扩大至262k后三次均低于0.99。它说明数值敏感性，与上述当前131k的合法反例分开记录。风险验证须报告真实早停次数、漏清率及区间；不能把少量零失败或高模型分数解释为确定性全清保证。
