# 版本与成绩

本包对应冻结候选 `problem3_v5_continuous`、`problem4_v5_visibility_discovery`；策略参数固定为 `adaptive`、`config=None`。算法、客户端和本地模型逐字节复制，指纹记录在 `source_manifest.json`。新写的只是启动、演练确认和日志入口。

这两个样本池分布不同，不能把均值差别当成算法改进。共同测试集只用于评估，没有据此调参；第四问尚未达到400秒/源目标。

可分享的完整汇总在 `版本与结果/problem3_7000例汇总.json`、`problem4_7000例汇总.json`。原候选冻结记录同时保留，其中的原目录路径是历史来源记录。包内没有7000例真值、逐例测试结果、旧平台日志或队号配置。

本包只在本地和纯内存假接口中做集成验证，没有启动或使用官方模拟器，更没有使用正式测试。平台表现仍需用户自行演练确认。核验内容包括默认不联网、完整演练标签确认、队号和端口、串行动作与原ID重试、拒绝响应不改状态、未知结果停止，以及新旧入口使用同一冻结算法。

最终检查通过：两题各3个早先已见训练案例，新包与原冻结版本的完整动作序列、计费统计和完成标志完全一致；纯内存连接流程检查通过。另已运行两题命令行本地自检及Windows菜单退出检查。检查未使用共同7000例，也没有任何真实网络请求。

Windows 菜单优先调用这台电脑已有的 Python 3.12.14、NumPy 2.3.5。第四问在其他依赖版本上的表现不能仅凭成功导入认定与本轮成绩等价。
