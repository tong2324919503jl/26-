## 直接使用

算法定稿后，在仓库运行一次：

```powershell
python scripts/run_balanced_search.py --run-id normal_v2_final
```

这条命令校验样例、分别测试两问当前`solve.py`使用的默认方案，并分别生成图。默认两问同时运行，每问内部的动作和案例按顺序执行；加`--jobs 1`可改为两问依次运行。不存在队友或历史方案的比较分支。

中断后使用相同参数加`--resume`继续；代码或数据变化时会拒绝续跑，应换一个新`--run-id`。重新完整运行也必须使用新名称，避免覆盖旧记录。

```powershell
python scripts/run_balanced_search.py --run-id normal_v2_final --resume
```

仅调整图形样式后，无需重新跑算法：

```powershell
python scripts/run_balanced_search.py --run-id normal_v2_final --plot-only
```

流程预览用`--limit-per-count 2`，表示从完整数据中取10至16源各2例，即每问14例。小规模预览保存在独立名称下，不是7,000例的完整实验，也不保证小样本仍保持完整正态形状。

```powershell
python scripts/run_balanced_search.py --run-id normal_v2_preview --limit-per-count 2
```

独立绘图入口处理子集时必须显式加`--allow-partial`，避免把小规模结果当作完整实验。旧`balanced_v1`的本地数据和`workflow_smoke`预览保留原样；读取已有批次时按其数据版本调度，不把旧结果并入新池。旧池不是本次上传的14,000例。

若只准备或检查样例：

```powershell
python scripts/prepare_balanced_search.py
python scripts/prepare_balanced_search.py --verify-only
```

## 构造难度

每种源数使用同一套1,000个等概率分位点。令`Φ`为标准正态分布函数：

`q_i = Φ(-3) + (i+0.5)/1000 × [Φ(3)-Φ(-3)]`，`z_i = Φ⁻¹(q_i)`，`d_i = (z_i+3)/6`。

再为每问、每种源数独立固定随机打乱排列。这是截断正态的分层分位数抽样，能稳定保证两端都有样例，不是1,000次互相独立的正态抽样。

| 构造难度区间（仅供审计，不拆分数据） | 每种源数例数 |
| --- | ---: |
| 较简单：z < -1 | 158 |
| 中等：-1 ≤ z ≤ 1 | 684 |
| 较困难：z > 1 | 158 |

参数`d`实际改变场景：

- 位置独立按面积均匀分布在半径`L=900+900d`米的圆内；`d`增大时可分布的空间更广。
- 各源接收半径为`R=1350-350d+150u`米，`u`逐源独立均匀抽取，始终落在1000至1500米内。
- 第三问全为全向源。第四问定向源数为`K=1+floor((N-2)d+u_K)`，以随机舍入保留变化，始终有1至N−1个定向源；从源中随机选择对应子集。
- 第四问每个定向源以概率`d`朝外、`1-d`朝内，再叠加±90°独立均匀方向偏差；所有相对朝向都有支持，包括接近擦边的朝向。

这里正态形状对应**预设环境的构造难度参数**，并不保证未定稿算法的实际耗时也呈正态分布，或逐例随`d`单调。外部几何审计按各源数分别检查空间分散和原点到接收区域距离随`d`的总体变化，不用当前算法的运行成绩筛选样例。中等环境的空间范围与旧样例池不同，不能将跨样例池的均值差异称为算法改善。

## 数据与统计

- 每个源使用不同频道。同一位置的误差由样例种子、频道及坐标固定，不靠重复读数平均降低误差。
- 样例使用独立的新种子域，保存逐文件校验值、生成器指纹及生成规则。已有数据被修改时生成入口拒绝覆盖。
- 策略在独立进程中仅接收公开动作响应，源数、位置与构造难度只由外部评估器用于核验、分组与绘图。
- 两项指标为每例清除比例`Nc/N`和平均定位清除时间`T/Nc`。总时间包含最后一次清除后的覆盖确认。统计保留失败案例；`Nc=0`时后一指标记为`null`，不会改成0或当作成功。
- 按源数展示两项指标及时间构成，不设置220/400秒通过率图。证书与实际全清分别记录。不同源数组的耗时比较是事后统计，不视为源数单因素的因果实验。

这些是自建本地样例及本地结果，不是官方演练或正式成绩。该样例池不宣称为独立留出集；若用于调整算法，应在实验说明中披露。旧冻结样例和结果保持原口径。

## 输出位置

| 内容 | 第三问 | 第四问 |
| --- | --- | --- |
| 固定样例和清单 | `problem3/examples/balanced_normal_v2/` | `problem4/examples/balanced_normal_v2/` |
| 每次批测、检查点及摘要 | `problem3/results/balanced/<run-id>/` | `problem4/results/balanced/<run-id>/` |
| 每种源数首例的轨迹 | 对应批测的`trace_samples/n10`至`n16` | 同左 |
| 统计图和逐图图注 | `paper/figures/problem3/<run-id>/` | `paper/figures/problem4/<run-id>/` |
| 当前配置的机制图 | `paper/figures/problem3/mechanisms/` | `paper/figures/problem4/mechanisms/` |

图形只保留坐标轴、单位、刻度、必要图例及数据标记。图内没有解释段落、版本、样本说明或结果评价；样本量、来源、失败计数、版本和解释保存在配套JSON/Markdown图注中。第三、四问不合图；同一问题的两项指标可组合为子图。

图形导出PDF、SVG和PNG，并在每问对应目录生成六页`figures.pdf`，每页一张图，便于逐张筛选。绘图需要matplotlib和NumPy，算法、数据生成和批测核心只需标准库。路径按脚本位置解析，允许从仓库外启动。
