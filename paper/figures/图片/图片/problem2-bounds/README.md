# 问题二两类评分上界示意图

两张图对应论文第 8--9 页的式 (14)--(17)，并与 `problem2/solve.py` 的实现保持一致。图中仅用于解释几何关系，不按比例表示数值结果。图内只保留必要变量，完整解释集中在图例中。

## 解析条带上界 `A(q)`

图 `analytic-strip-bound.svg` 展示：首读数外包被宽度 `2w1` 的第一条带包住，第二读数被宽度 `2w2` 的第二条带包住，两条中心线夹角至少为 `beta0`。两条带交集被平行四边形外包，其直径给出

图中的红色线段连接条带交集外包的两个边界点；它表示外包直径，而不是两条中心线的夹角。图中的 `β₀` 弧线只连接两条虚线中心线，表示它们的锐角夹角。两条半宽分别用垂直于对应中心线的红色短线表示。

`A(q) = 2 sqrt(w1^2 + w2^2 + 2 w1 w2 cos(beta0)) / sin(beta0)`.

当 `h0 <= 0` 或 `beta0 <= 0` 时，程序令 `A(q)=+infinity`，表示该解析放松无法提供有限保证，而不是断言真实定位一定失败。

## 几何外包上界 `B(q)`

图 `geometric-outer-bound.svg` 展示：先构造与第二读数无关的 `Q(q)`，再将连续读数划分为中心 `psi_k`、半步宽 `delta` 的角度单元。对每个单元同步放宽扇区半角、前向投影下界和条带半宽，得到 `P_k(q)`，满足

`U(q, psi) subseteq P_k(q)`，因此

图中的红色线段两端都落在紫色外包单元 `P_k(q)` 的边界上，因此它是该单元直径的示意，而不是内部任意线段。

`B(q) = max_k diam(P_k(q))`.
