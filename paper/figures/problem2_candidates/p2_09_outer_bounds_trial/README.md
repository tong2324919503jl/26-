在原图三个读数及单元直径不变的条件下，显式标出Q由第一扇区、第一条带、有效投影下界与三个圆的360边外包求交。(a)—(c)为三组读数单元；(d)目标圆外切边界、(e)第二距离圆外切边界展示圆弧与外包折线，(f)第一距离圆局部裁边对应(c)圆圈内的实际裁边。

本原点算例中目标圆1800米被第一距离圆1500米包含，第二距离圆1000米未进一步裁切Q；(a)(b)三圆约束均不活跃。(d)(e)展示各自圆边界的外切几何，不对应(a)(b)单元附近的位置。(c)实际外切边的法向为359度，跨度2.377米，单元顶点最大越出真实圆约1.884毫米。最下排横轴为切向米，纵轴为法向毫米，采用不同显示比例以分辨外包增量；360边数未减少，原图几何与1.05度评分半角未夸张。

记号：D0为目标圆，D1为第一距离上界圆，D2为第二距离上界圆；W1、T1、H1分别为第一扇区、第一条带和有效前向投影约束。
