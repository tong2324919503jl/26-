# 第四问：定向与全向混合源的搜索清除

默认策略由 `current_policy.py`（`problem4_v5_visibility_discovery`）组合，继承原 `speed_policy.py` 的认证布局和保守几何。源位置、半径、朝向及总数不提供给策略；自建仿真结果与旧平台记录均不当作新版正式成绩。

## 1. 时间与完成条件

总时间为 `路程/5 + 5×检测数 + 切频数 + 3×失败清除数 + 5×成功清除数`。包含最后一次清除后的覆盖确认时间，清除动作不切换测向机频道。

必须完成覆盖并清除所有已发现源，或实际清除上限 16 个源。发现 16 个可停止继续扫未知频道，但仍须清除这 16 个才结束；结果分别记录 `completion_certified` 与 `coverage_complete`。400 秒/源为本轮自定优化目标，不是官方阈值。

## 2. 22 点连续覆盖证明

`search_layout.py` 保存冻结的 22 个点：原点、7 个内点和14 个外点，取自队友第三轮方案。原 ZIP、坐标及原证书保留指纹；生产不读取 ZIP 或临时解压文件。

设源位置为 `g`，其 1000 米邻点为 `N(g)`。任意发射闭半平面都有可收信点，当且仅当

\[
g\in\operatorname{conv}N(g).
\]

若成立，对任意朝向 `n`，把 `g` 写成邻点凸组合，便有加权内积 `Σλᵢ nᵀ(vᵢ−g)=0`，不可能所有内积为负；若不成立，则存在分隔半平面排除全部邻点。

本项目独立程序重新认证：全部点凸包严格包含目标圆；枚举检测点确定的每条有向线，只取其严格左侧点，检查这些点的 1000 米圆盘覆盖目标圆与左闭半平面的交集。使用 Voronoi 单元顶点、直边与圆交点、圆弧距离极值形成有限检查。附近零、一、二点及共线退化由凸包包含条件和相应分隔线处理，不依赖密集网格接受布局。

`results/coverage_certificate_v4.json` 对实际生产坐标给出：凸包内切半径 1800.281070 米；448 个有效有向点对；最大接收距离上界 999.624551 米，小于 1000 米约 0.375 米。坐标与证书必须配对，舍入或移动后需重新认证。不声称 22 是最少点数，21 点也不必然比 22 点更快。旧 23 点及25点三角覆盖保留为对照。

## 3. 保守定位与阴性历史

每次阳性读数加入 ±1.005° 扇形及半径 1500 米圆盘的外包约束，保留真实候选。固定地点不重复测量平均。无信号可能由距离不足或发射背面造成，不能直接删去一个 1000 米圆盘。

令最近阳性点为 `p`，读数方向及法向为 `e,u`，候选区纵向范围为 `[a,b]`，先取 `t=a+0.2(b−a)`，探测

\[
q_\pm=p+te\pm wu,\quad
w\ge\max(15,\min(140,0.04t)),\quad w>t\tan(1.005^\circ).
\]

优先访问较近一侧，阳性出现即更新。两探点不能同时保证覆盖候选区的接收距离时，逐步将截面移向中部，但能否裁剪仍由最终显式检查决定。

只有候选区所有顶点到两探点都小于 999.999 米时，两次阴性才排除 `eᵀ(g−p)≥t`：阳性点与源的连线位于发射半平面内，其与截面的交点却夹在两个必位于发射半平面外的阴性点之间，产生矛盾。没有距离保证或缺少一次探测时不作此推断。

保存历史阳性点 `A` 和阴性点 `B,C`，若能证明两阴性点在接收范围内，也可排除使线段 `[A,g]` 与 `[B,C]` 相交的位置。为减弱距离证明要求，将长候选区分为12片，逐片验证：阴性点 `Q` 距所有顶点小于 1000 米，或某历史阳性点 `P` 满足

\[
2(P-Q)^\mathsf{T}g<\|P\|^2-\|Q\|^2,
\]

即 `|Q−g|<|P−g|≤R`。线性不等式只需检查顶点，两个阴性点可分别使用不同阳性点。扣除禁区后取剩余凸包只会变松；碎片过多则放弃本次可选收紧。

## 4. 减少专门测量与失败后的折返

搜索站新发现大候选区域时，比较共用 50 米基线的预期收缩收益与绕路成本，收益足够才对新频道共享补测。

其他已访问停点使用 `bystander.py` 筛选补测：由候选中心产生假想无噪声方向，若相交后的外包半径小于 75 米及原半径的55%，并通过距离和重复位置过滤，才真正测量。假想方向只决定是否值得测，实际几何始终使用真实响应。

`optical_repair.py` 处理清除失败：从辅助候选集合中扣除失败点20米圆盘的内接16边形，保留剩余凸碎片并集。对候选光学点按“能覆盖的碎片总面积 / (3 秒 + 行走时间)”排序，避免把已知空洞又填回。

面积只是排序启发式，不是已校准的命中概率。该修复只处理长不超过200米、宽不超过32米的条带，每源额外最多16次动作，碎片超过200个便返回原定位器。候选过滤和次数上限可能失去完整覆盖，所以**这16次不是独立完成证书**；硬候选区与原兜底保留，只有实际清除成功才计入完成。

## 5. 路线与有限兜底

搜索点和已知源候选中心共同规划开放路径，比较最近邻、插入、正反角度及上一轮未执行路线，以2-opt和短链搬移改进。另用固定离散位置、三种半径、全向或八个朝向近似后续扫频成本。先验只影响路线，不代表官方分布，不参与完成证明。

覆盖圆半径不超过19.99米时清除有保证；半径不超过55米可先试中心。成对探测最多5轮，之后仍未完成时，以边长26米网格覆盖硬候选区，保留所有相交格中心。格内任意点距中心至多 `13√2≈18.385<20` 米，保证有限覆盖，且不受发射方向限制。附加光学失败后同样返回此兜底。

完整性以题设误差、接口执行正确、预算足够为前提；连接异常或预算耗尽必须报告未完成。这里没有证明全局最短路线或每个案例都能通过速度阈值。

## 6. 证据与入口

当前比较见 `validation/speed_v4/p4_{development,holdout,stress}_v3.json`：开发384、留出512、压力256例，策略在独立评价前冻结。保持相同案例、噪声与物理计时，分别报告均值、P90、全清数和400秒阈值通过数。旧版成绩与新版分开，不能将不同集合的均值直接配对。

实现分为 `search_layout.py`、`coverage.py`、`localization.py`、`shared_baseline.py`、`bystander.py`、`optical_repair.py`、`routing.py`，由 `speed_policy.py` 组合。正式几何测试包括定向阴性距离前提、退化覆盖、失败圆盘边界和附加光学次数上限。原25点、上一版23点及上一轮21点分支保留为对照，不改变历史结果。

平台演练、正式三次、请求重试和原名加密日志导出见 `simulation_guide.md`。当前本地新版本不自动具有旧平台演练成绩。

## 20260912 新版：可见性、可中断定位与发现排序

`visibility.py` 用相容区长轴的5个面积加权位置节点、连续发射朝向区间和接收半径区间给成对探测排序；纵向分位候选为0.10、0.20、0.45、0.70，仍需原有距离与夹角前提才能使用真实双阴性裁剪。节点与积分权重不是硬覆盖，不删除真实候选，不授权停止。

`incremental_localization.py` 与 `incremental_visibility.py` 使定位每次执行一个测量或清除动作，近距离反馈仍立即同点清除。每源保留探测轮数、未完成探测对、重复位置及光学兜底队列，跨任务调度时不丢失证据。其他停点获得新阳性时重新构造探测对；未完整执行的双阴性对不能裁剪。射频最多5轮后继续有限光学兜底。

`discovery_route.py` 与 `global_discovery.py` 按几何生成等面积位置节点、三种接收半径并解析积分完整朝向圆，估计每个扫描站可减少多少未知频道检测。总源数10至16的均匀假设仅用于排序。默认比较原路线和最多4个扫描首站、3个已知源首动作的完整路线，以移动时间与预计扫频成本评分；实际执行仍按真实响应计时。未执行的认证搜索站不因概率估计而消失，实际清除16个源或完成覆盖才允许结束。

此前章节的v4耗时与比较为历史记录；当前原包汇总及本次迁移等价验证见 [新版记录](../validation/practice_v5/README.md)。
