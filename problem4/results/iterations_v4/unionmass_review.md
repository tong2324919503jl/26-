# 第三轮队友包：定位与光学清除融合

来源：根目录 `B题第三四问_第三轮演练包.zip`，原件未修改。SHA256：`bce6c749b633275e01c20913d1b9980b4f810cf6fad57f9de58732edbe5b4332`。本次审查包内 `problem3/phase3_optical.py`、`phase3_localization.py`、`geometry.py`、`policy.py`，并检查调用它们的 `phase3_route.py`。

## 取舍

- **采用有界光学修复。** 清除失败表示源在此点 20 米圆盘外。扣除该圆盘的内接多边形，保留剩余凸碎片的并集；候选清除点按“能覆盖的碎片总面积 /（3 秒 + 行走时间）”排序。相比当前 P3 窄带一次固定排序，这能利用刚得到的失败位置并重新排序。
- **保留完整兜底。** 面积只是选点权重，不是概率校准或完成证明。每源额外最多 16 次清除、最多 200 个碎片；超过上限或条带长宽不适用时返回原策略。候选点过滤与数量上限可能使可选点不再覆盖全域，所以不能把本模块描述为完整光学覆盖证书。仅成功清除反馈返回成功，硬候选区域与原有限光学覆盖均保留。
- **不重复加入已有阴性锥。** 两阳性点与一阴性点的凸可见锥，在 `experiments_v3/convex_history.py` 已有等价实现。新开发集首 48 例，Shared21 约 457.518，加入它约 457.363，收益很小。P3 队友版只扣除阴性点 1000 米盘，弱于现有阳性—阴性距离半平面约束，故不替换。
- **不重做相同测点参数搜索。** 队友的多分位推进、25/65/130 米侧移和三种假想噪声，属于 v3 已试过的单步有限前瞻。加权中心线拟合与可见性概率也只是行动启发式，不能收紧硬误差界。

几何审查未发现上述有限兜底与内接盘扣除的数学漏洞。队友采用 1.005001° 角误差、外接接收圆、全顶点复核包围圆，均保守。成对阴性裁剪需要它已经检查的接收距离保证及侧移在角域两侧的条件；不能去掉这些检查。退化共线锥不裁剪。其几何空集时恢复首次观测大区域仍是安全外界，但不应掩盖异常计数。

## 实现与验证

- 独立原型：`problem3/experiments_v4/unionmass.py`，算法已冻结。生产版本由主任务复制到 `problem4/optical_repair.py`，不依赖实验模块。接入点在首次清除失败后，至多执行有限光学子流程，随后返回原控制器。
- 生产单元测试：`python -m unittest problem4.tests.test_optical_repair`，3 项通过。测试覆盖两重失败盘与 20 米边界外点保留、100 组旋转窄片及退化区域、与几何收缩独立的 16 次动作上限。仅候选选点不改变硬区域。
- 记录审计：`python -m problem3.experiments_v4.audit_unionmass`。本轮自有 2784 条记录全部全清且有证书，计时恒等式 `T=路程/5+5×测量数+切频数+3×失败清除数+5×成功清除数` 最大误差 5.46×10⁻¹² 秒。
- 主要组合记录：`unionmass_development_v3_96_Predicted4Policy_P4PredictedUnionmassPolicy_P4PredictedNearestPolicy.json`、`unionmass_development_v3_384_P4PredictedUnionmassPolicy.json`。Shared21/光学单独消融在同目录 `unionmass_development_v3_384_Shared21Policy_P4UnionmassPolicy.json`。

复现组合：`python -m problem3.experiments_v4.unionmass 4 384 P4PredictedUnionmassPolicy --split development_v3`。默认拒绝覆盖已有结果，需先指定新的结果文件或在隔离副本运行。所有策略仅接触公共观测；真实源只供仿真器与结束后的评分使用。
