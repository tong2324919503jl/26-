## 同口径改善与时间折中

所有点均使用相同的目标圆条件化先验、360边圆外包和0.1°读数步长重新评分。完整原始数值、移动预算与精度敏感性见 [strategy_comparison.json](strategy_comparison.json) 和 [strategy_comparison.md](strategy_comparison.md)。

| 场景 | 原仓点的几何上界/m | 队友点的几何上界/m | 融合点的几何上界/m |
|---|---:|---:|---:|
| 原点向东 | 115.693039 | 113.037691 | 112.329304 |
| (1500,0)向东 | 54.023570 | 15.966125 | 15.768784 |

融合点相对原仓点的同口径保证指标分别改善约2.91%和70.81%。原仓的131.221007米是较保守的解析条带上界，不能直接与112.329304米相减后称为真实定位精度提升。队友边界点原记录为16.005261米；合并先验保留首距下界后，同一点重评分为15.966125米。

默认允许10%上界容差时，原点案例的最短已访问候选将移动与检测时间降至193.857秒，几何上界为122.865米；边界案例为57秒、17.143米。这些只是在同一已访问集合中的折中点，不是连续域最快点。

精度敏感性：固定默认融合点，360边/0.1°的112.329304米在720边/0.05°下变为111.793188米；同时采用更细空间搜索可得到111.687447米。改变精度会改变上界和候选排序，尚未证明连续全局最优。

## 提前停止的等价性与实际效果

对照仅改变提前停止开关，统一几何、候选域、误差和网格均相同。四组单点评分场景各14点，最终评分及排序全部一致；默认完整选点的各层推荐、最终推荐、近优备选和非劣集合也一致。

默认全流程扫描从3,205,440格减至3,201,498格，节省3,942格（0.123%）。22次提前停止全部发生在第一层粗评分，后续细层和最终复核均未触发。单次耗时为完整扫描17.967秒、提前停止18.635秒，未观察到耗时收益；这次耗时观测不能作普遍速度保证。详细分层计数及交替运行的单点评分耗时见 [scoring_benchmark.json](scoring_benchmark.json) 和 [scoring_benchmark.md](scoring_benchmark.md)。

当B小于A时必须扫完。min本身只收紧保证，提前停止只在已扫最大值达到A时减少工作；此时完整B记null，由A提供最终上界，不能把部分最大值充作完整几何保证。

## 复现和限制

```text
python problem2/solve.py
python problem2/compare_strategies.py
python problem2/benchmark_scoring.py
python -m unittest discover -s problem2/tests -v
python scripts/verify_project.py
```

全部默认路径相对于脚本文件；仓库外启动由统一验证入口再次核验。完整比较通常约一分钟量级，取决于本机负载；`compare_strategies.py --quick`只省略预算/精度/空间细化，默认写入独立的 `results/quick/`。固定比较案例参数若被改动会明确报错，避免比较口径静默漂移。

保证来自四圆盘推导、圆外包与半格增宽的集合包含关系；浮点计算和有限测试不是严格区间算术认证。1800米目标圆只约束源，机器人可在圆外。原点案例仍不能保证仅测向两次后就进入20米光学清除范围；覆盖范围应以最小覆盖圆判断，不能把直径的一半普遍当成覆盖半径。
