# 概率提前停止：验证口径

本轮是自建环境中的风险实验，安全默认仍为 `problem3_v4 / problem4_v4`。

- 先验分支：`nominal`（均匀分布）、`robust`（五种先验取较低全清概率）、`guarded`（再给粒子积分加数值误差保护）。主对照固定为 `nominal=0.99` 与 `guarded=0.99`。
- 预设阈值：0.80、0.90、0.95、0.975、0.99、0.995、0.999、0.9999。全部报告，不能看完留出集后只保留有利阈值。
- 每问新开发256、校准512、留出2048、压力512例；16类场景，包括边界外向、切向、最短接收半径、簇团和少量隐藏源。种子互不重叠，旧 v3 集不参与本轮批量结果。
- 先完成开发检查，再冻结算法和参数，之后校准、留出与压力结果只作验证；若要据此改策略，须另换保留集。
- 采集完整安全基线，每个阈值取**第一次**合格跨越；预测只读当时的公开历史，之后才由外部评估器用真值检查有无漏清。另实际执行提前停止分支核对退出时间、清除数量与离线回放一致。
- 计时到实际退出。漏清例单列失败，不能以低 `T/已清数量` 冒充达标；并列全清率、漏掉的源数、提前停止后的漏清率、认证完成数和成对节省时间。全清子集均值仅作有选择偏差的描述。
- 统计单位是一整局，不能把同一局多次概率检查当作独立样本。零失败也不证明零风险；二项上限只作假设独立同分布时的参照，不能替代官方平台分布或对抗布局的保证。
- 定向源的未知方向、接收半径和位置作为同一个固定源配置，统一判断是否躲过全部扫描；重复 `no_signal` 不当作独立证据。粒子中的零幸存者不当作概率1。
- `guarded` 只控制有限先验模型内的积分误差，不能控制模型与真实场景分布的偏差。提前退出始终 `completion_certified=false`；16次成功清除或原覆盖证明仍可认证。

二项置信限参考：[NIST exact binomial limits](https://itl.nist.gov/div898/software/dataplot/refman2/auxillar/exacbino.htm)。零失败时单侧95%上限为 `1-0.05^(1/n)`。本实验的固定族配额及分布变化不满足简单全体同分布解释，报告会保留这一限制。
