# 正态形状均衡样例核验

2026年9月12日完成数据构建和本地核验。新数据为`balanced_normal_v2`，共14,000例：问题三、四各7,000例，10至16源各1,000例。

每组的连续构造分数按截断正态[-3,3]的等概率分位点取值，再固定随机打乱。z小于-1、中间[-1,1]、大于1分别为158、684、158例。分数会改变位置范围、接收半径及第四问的定向条件，未使用任何求解成绩选择样例。

已通过的核验：

- 全部14,000例的源数均衡、几何合法性、唯一标识、唯一种子、唯一物理配置和逐条可重建性。
- 两份数据的JSONL、分布报告、说明文件和生成器指纹一致；数据文件使用LF。
- 独立用Kruskal重新计算空间分散指标，用笛卡尔半圆盘投影重新计算原点到接收区域距离；全部案例统计与生产报告相差小于5×10⁻¹⁰。
- 14组内构造分数与空间分散的Spearman相关为0.5813至0.7442，与原点到接收区域距离为0.7977至0.9363，与平均接收半径为-0.9826至-0.9696；环境强度总体按预设方向变化。
- 仓库完整验证通过，共216项自动测试；新数据生成、历史版本调度、损坏拒绝和策略隔离均覆盖。
- 从仓库外启动新默认一键流程，两问各14例完成并分别生成6张图。这28例只验证集成，未执行14,000例完整求解，也不是官方测试。

构造参数的正态形状不保证真实求解耗时正态，也不保证逐例耗时随分数单调。新旧样例池的先验不同，不能将跨池成绩变化称为算法改善。

核验明细及指纹见[JSON记录](normal_dataset_validation.json)，完整仓库验证见[报告](report.md)。数据说明：[问题三](../problem3/examples/balanced_normal_v2/README.md)、[问题四](../problem4/examples/balanced_normal_v2/README.md)。后续测试和绘图见[使用说明](balanced_search.md)。
