## 本轮融合了什么

- 采用队友的22点非均匀布局，已用两套独立方法验证连续覆盖。
- 保留我方历史观测定位和50米共享补测；借用队友的收益筛选，减少作用不大的旁路补测。
- 光学清除失败后，保留排除圆盘形成的多个候选碎片，优先尝试单位时间覆盖候选面积较大的位置。
- 每个源最多额外做16次这类尝试，之后仍有原来的定位和有限光学覆盖兜底。

定向源背面无信号不能直接排除接收圆盘。必须完成覆盖并清除已发现源，或实际清除16个源，才确认结束。

同批384例开发样本中，上一轮最好实验 **444.38→440.16秒/源**，全部清除。冻结后的留出、压力比较及波动见 [本轮报告](../validation/speed_v4_summary.md)。**仍未达到400秒均值目标；本地结果不是官方成绩。**

数学说明见 [model.md](model.md)。生产入口在 `speed_policy.py`，仅需 Python 3.10以上和标准库，不依赖实验目录或队友ZIP。自选路径按 `problem4/` 解析。
