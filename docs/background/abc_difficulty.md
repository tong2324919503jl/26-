# 2026 国赛 A、B、C 题完成难易度分析

**总体判断：对具备基本 Python / MATLAB 编程能力、没有专项数值仿真经验的队伍，完成整题的难度大致为 C < A < B。** C 题相对稳妥，A 题专业门槛高，B 题后两问的算法与测试风险最大。

这里评估的是“建立合理模型、算出可信结果、完成要求的提交材料”的难度，不是获奖概率。等级为：较易、中等、较难、很难。判断基于当前文件夹中的题面与附件，尚未实际求解或运行模拟器。

## A 题：药材的烘干问题

| 问题 | 难度 | 需要完成什么、主要卡点 |
|---|---|---|
| 第 1 问 | 中等 | 模拟预热阶段温度与水分的空间分布。需要建立传热、扩散方程，处理圆柱中心与表面边界；扩散系数随含水率变化，不能只做简单曲线拟合。 |
| 第 2 问 | 较难 | 扩展到整个烘干过程。密度、比热、导热系数及扩散系数随温度或含水率变化，温度与水分相互影响，数值求解和稳定性验证是重点。 |
| 第 3 问 | 中等，依赖第 2 问 | 延长仿真，寻找所有位置含水率均低于 0.15 的时刻。第 2 问正确后，新增工作较少；要检查最湿位置，不能用平均含水率代替。 |
| 第 4 问 | 很难 | 加入药材收缩，利用半径数据描述随时间变化的计算区域。难在移动边界、坐标变换、收缩与水分守恒的一致性，以及变化半径下的结果输出。 |

**整题特点：前面模型是否正确决定后续能否推进。** 有偏微分方程、传热传质或有限差分经验的队伍更适合；对这类队伍，A 题可能比 C 题更顺手。

## B 题：无线电干扰源的快速自动定位与清除

| 问题 | 难度 | 需要完成什么、主要卡点 |
|---|---|---|
| 第 1 问 | 较易 | 用带角度误差的方向约束求定位多边形，再计算最远点对距离。几何算法较成熟；“区域直径”与“能覆盖区域的圆的直径”不能直接等同。 |
| 第 2 问 | 中等 | 选择第二个检测点，使定位更准确。需要定义“定位效果好”的指标，并平衡交会角度、未知目标距离和能否继续收到信号，给出候选区域。 |
| 第 3 问 | 较难 | 实现全向源的搜索、定位、清除和结束判断。难点是目标数量未知，要保证不遗漏，同时减少移动、测量和切换频道的总耗时，并完成模拟器联调。 |
| 第 4 问 | 很难 | 在第 3 问基础上加入未知方向的定向源。无信号可能来自距离或朝向，不能据此直接排除目标；搜索覆盖和全部清除的判断更难。 |

**整题特点：前两问容易入手，后两问工程量和策略难度陡增。** 第 3、4 问各要求三次正式测试并导出日志，正式机会有限，需要预留充分演练时间；适合算法与编程能力强的队伍。

## C 题：微网与外部电网电力调控策略

| 问题 | 难度 | 需要完成什么、主要卡点 |
|---|---|---|
| 第 1 问 | 较易 | 已知一天的负载、电价和光伏预测，优化购电与电池充放电。可从线性规划入手；重点是功率与电量换算、充放电效率、电量上下限及日初日末电量相同。 |
| 第 2 问 | 中等 | 用当时可获得的信息制定每日计划，面对实际偏差计算高价紧急购电。难在负载与光伏预测、保留多少备用电量，以及连续多日的电池状态衔接。 |
| 第 3 问 | 较难 | 每六小时获得新预报后重新优化，权衡调整费用与紧急购电费用。难在多轮计划更新、预报与十分钟数据对齐、费用计算及判断调整是否划算。 |
| 第 4 问 | 较难 | 加入波动电价，重新完成第 2、3 问。大部分框架可复用，但要说明未来电价在决策时是否已知；若未知，需要预测或情景处理，并完成两套结果比较。 |

**整题特点：基础模型成熟，逐问扩展较自然，完整完成的把握相对更大。** 主要风险是误用未来实际数据、重复计算费用和电池电量衔接错误；相对容易完成，不等于容易做出有竞争力的结果。

## 选题建议

- **优先考虑完成度：选 C。** 适合数据处理、预测和优化基础较好的队伍。
- **擅长物理建模与数值求解：选 A。** 关键是尽早跑通并验证前两问。
- **擅长几何算法、搜索策略和程序联调：考虑 B。** 不要仅因前两问简单而选择它。
